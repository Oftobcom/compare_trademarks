### Анализ приложенных файлов

Приложенные скрипты (`compare_trademarks_v05.py`, `compare_trademarks_v06.py` и финальная версия `compare_trademarks_v07.py`) представляют собой эволюцию инструмента для автоматического сравнения товарного знака (эталона) с коллекцией изображений.

В актуальной версии **`compare_trademarks_v07.py`** реализовано:

* **6 метрик сравнения:** SIFT, ORB, Color (с опциональным игнорированием белого фона), pHash, SSIM и Shape (контуры + Hu-моменты после выравнивания).


* **Умная загрузка:** Поддержка альфа-канала в PNG (композиция на белый фон).


* **Отчёты и визуализация:** Генерация CSV, JSON и интерактивных HTML-отчётов с миниатюрами и галереей лучших совпадений (`--visualize --top-vis N`).


* **Классификация рисков:** Автоматическое разделение совпадений на категории `HIGH`, `MEDIUM` и `LOW` по уровню сходства.

### Где взять файлы изображений для тестирования?

Сами скрипты не содержат встроенных ссылок на скачивание датасетов — они рассчитаны на работу с **локальной папкой с изображениями**, которая передается через аргумент `--collections` (по умолчанию ожидает папку `collections`). Поддерживаются форматы: `.jpg`, `.jpeg`, `.png`, `.bmp`, `.webp`, `.tif`, `.tiff`.

Для тестирования скрипта вы можете использовать следующие варианты:

#### 1. Создание собственной локальной коллекции (самый быстрый способ)

* Создайте в папке со скриптом директорию `collections/`.


* Загрузите туда несколько десятков изображений разных логотипов, иконок или картинок из интернета (включая вариации одного и того же логотипа с разным углом поворота, масштабом или фоном).
* Подготовьте эталонный файл (например, `logo.jpg`) и запустите скрипт:


```bash
python compare_trademarks_v07.py --new logo.jpg --collections collections --html report.html --visualize --cache

```



#### 2. Открытые датасеты логотипов (для глубокого тестирования)

Если вам нужны специализированные академические датасеты товарных знаков, вы можете найти и скачать их на открытых платформах:

* **FlickrLogos-32** — классический и широко используемый датасет для задач поиска и распознавания логотипов (содержит изображения брендов в реальных условиях).
* **BelgaLogos** — база данных изображений с логотипами, извлеченными из новостных лент.
* **Kaggle** — выполните поиск по запросам *"Logo dataset"* или *"Trademark detection"*, где сообщество часто публикует готовые выборки изображений брендов.

#### 3. Использование поисковых систем

Вы можете быстро собрать тестовую выборку, сохранив логотипы известных компаний (например, из Википедии или официальных сайтов) и их стилизации, чтобы проверить, как алгоритм справляется с определением степени схожести и классификацией рисков (`HIGH` / `MEDIUM` / `LOW`).
